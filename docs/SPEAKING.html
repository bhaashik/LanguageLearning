Choose Malayalam or French in the language selector. Each language has its own progress, recap, review queues, and voice preferences. Useful constructions has 16 units per language, from first sentences to introductory intermediate patterns. Each unit has function words, two model sentences with morpheme glosses, constraints, and recall exercises. All correct answers and their constraints appear after an exercise. These are starter courses, not a certified proficiency curriculum.

1. A small practice loop

  1. Open a construction unit, read its function words and constraints, and listen to a model sentence.
  2. Try its written recall quiz. This is where endings and grammatical choices are checked.
  3. Choose Say this phrase or Speak & listen. Listen again, then read or recall the sentence aloud.
  4. Inspect the ASR transcript. Recognition errors are possible. A transcript match is not a pronunciation, accent, or fluency grade; ASR can infer grammatical spelling from context.
  5. Come back when the item is due. You can also go anywhere and practise early.

French has many silent agreement endings: ASR cannot distinguish all of parle/parles/parlent or verify every written -s/-e. Malayalam ordinary finite verbs generally do not agree with subject person/number/gender, but pronoun case, tense forms, and case endings still matter. The course teaches these differences explicitly.

2. Spacing and scores

A successful due review advances to 1, 3, 7, 14, then 30 days; the final stage stays 30 days apart. An error resets the item to review now. Early successful practice counts in the score but neither advances the stage nor postpones the due date. No background notifications or account synchronization are required: due lists are calculated when you open Bhaasa.

Recall quizzes and speaking transcripts use separate schedules and scores. A failed connection, microphone denial, silent/empty recording, or malformed recognition response adds no speaking score. A completed nonempty transcript can be a mismatch, which schedules another speaking review now. The same recording cannot be scored repeatedly in one open practice attempt. Recording/importing new audio starts another attempt. Correct recall does not mark the speaking queue mastered, or vice versa.

Practice and Progress show the intervals and upcoming recall items; speaking review links open due phrases. Each language resumes its own last page. Export progress separately in each language; progress JSON includes both recall and speaking history, while audio still needs its own ZIP export.

Gateway mode first records locally. You can play your recording and choose Save to My recordings, which stores it under the item’s language/section/provider/model/voice hierarchy. Leaving the page, changing language, or backgrounding the native app stops recording and cancels pending recognition. Failed requests are never retried automatically. Use Check ASR connection for configuration status; this sends no recording and makes no paid transcription request.

4. Configure the local server

For the web app on your computer, use Node 24 and add the desired variables to the repository’s ignored .env.local, then restart npm run dev. For the desktop package, use providers.env in the directory shown in Desktop settings and restart the app. No API key belongs in a browser field, compiled app, URL, progress backup, or Git commit.

Gateway address: http://127.0.0.1:4173/api/transcribe for the default local web server; http://127.0.0.1:4174/api/transcribe for the desktop package. An installed mobile app needs a private reachable HTTPS gateway instead; see the mobile guide.

OpenAI transcription

BHAASA_ASR_OPENAI_API_KEY=YOUR_OPENAI_API_KEY
BHAASA_ASR_OPENAI_MODEL=gpt-4o-mini-transcribe
# Optional exact model allowlist, if available to your account:
BHAASA_ASR_OPENAI_MODELS=gpt-4o-mini-transcribe,gpt-4o-transcribe,whisper-1

OpenAI uses /v1/audio/transcriptions with an audio file and a two-letter language hint. A TTS OpenAI key can be reused when the TTS provider is OpenAI; a provider-specific ASR key takes precedence. Another provider’s key is never borrowed. An API subscription/account, model permissions, quota, and actual language quality must be checked separately.

Gemini audio input

BHAASA_ASR_GEMINI_API_KEY=YOUR_GOOGLE_API_KEY
BHAASA_ASR_GEMINI_MODEL=YOUR_AVAILABLE_AUDIO_INPUT_MODEL_ID

Use an exact Gemini model ID that accepts audio input and JSON output, not a provider label such as “Gemini” and not merely an audio-output/TTS model. This adapter requests a literal transcript and rejects incomplete or malformed results. It supplies no expected sentence and does not ask the model to correct the learner’s grammar. A configured Gemini OCR key/model does not automatically configure ASR: the input capability and settings are separate.

Local Whisper / OpenAI-compatible service

BHAASA_ASR_COMPATIBLE_URL=http://127.0.0.1:8080/v1/audio/transcriptions
BHAASA_ASR_COMPATIBLE_MODEL=YOUR_INSTALLED_TRANSCRIPTION_MODEL
# Only if your local service requires a key:
BHAASA_ASR_COMPATIBLE_API_KEY=YOUR_LOCAL_SERVICE_KEY

The service must accept OpenAI-style multipart fields file, model, language, response_format=json, and return {"text":"literal transcript"}. A multilingual Whisper-style engine can operate offline after its model is installed. Bhaasa does not download or install the ASR model.

Custom ASR adapter

BHAASA_ASR_CUSTOM_URL=http://127.0.0.1:8081/transcribe
# Optional:
BHAASA_ASR_CUSTOM_API_KEY=YOUR_ADAPTER_KEY

The companion sends POST JSON {audio: "data:audio/...;base64,...", language: "ml" | "fr", model?: "configured-id"}. Return {"text":"literal transcript"}, or an empty string for silence/unintelligible audio. A configured key is passed only as a server-side bearer header. The custom adapter is reached through Bhaasa’s gateway; the browser never gets its key. Every provider supports optional BHAASA_ASR_<PROVIDER>_MODELS allowlists. Leave the app’s Model ID blank for the gateway default.

5. Native mobile origins

Alongside the existing OCR/TTS origins, permit installed-app ASR origins on your private HTTPS gateway:

BHAASA_ASR_ALLOWED_ORIGIN=https://localhost,capacitor://localhost

Append your exact browser origin if needed. CORS is not user authentication; keep the gateway private or apply access controls. The portable desktop server accepts only its own loopback origin and is not exposed as a phone/public server.

6. French audio and transcriptions

TTS requests and native device voices now follow the selected language (ml-IN or fr-FR). Install an appropriate voice where available. Word/phrase IPA is a teaching model, not a verified recording. French Devanagari uses rough conventions such as उ̈ /y/, ए̈ /ø/, अ̈ /œ/, and ऱ /ʁ/; they are not ordinary Hindi sound equivalents.

Speech comparison normalizes Unicode, case, punctuation, and spacing, preserving accents and inflectional spelling. It shows a word-overlap measure and the literal transcript. Models may normalize numbers or joining differently; use the transcript to identify recognition problems rather than treating every mismatch as poor pronunciation. The model’s language understanding can also conceal a spoken mistake.

7. Troubleshooting

  • No browser ASR: choose a gateway source and record/import audio.
  • Microphone denied: enable permission in device/browser settings, or use an audio file.
  • Greyed-out Check my speech: stop recording, select gateway mode, provide an audio clip and gateway address, and make a new attempt if this recording was already scored.
  • Provider/model rejected: check the exact ASR model ID and server allowlist, then restart. OCR and speech-output model settings are separate.
  • Empty/incomplete transcript: nothing is scored; try a shorter clear phrase or another supported provider/model.
  • Progress seems missing: check the learning language, browser/profile, origin, and port; import the matching language’s progress/audio exports.
